# COVID-19 Data Analysis and Visualization with Python

## Project Overview

This project explores global COVID-19 data using Python to analyze the spread and impact of the pandemic across different countries.

The analysis focuses on confirmed cases, deaths, recoveries, active cases, testing statistics, and country-level comparisons. Interactive visualizations are used to present trends and communicate insights effectively.

## Objectives

- Analyze global COVID-19 statistics.
- Compare confirmed cases, deaths, recoveries, and active cases across countries.
- Identify the most affected countries.
- Examine death-to-confirmed and death-to-recovered ratios.
- Explore population-to-testing ratios.
- Analyze COVID-19 trends over time.
- Create interactive data visualizations.

## Tools and Technologies

- **Python** – Data analysis and programming
- **Pandas** – Data manipulation and cleaning
- **NumPy** – Numerical computations
- **Plotly Express** – Interactive visualizations
- **Plotly Graph Objects** – Advanced charts
- **Jupyter Notebook** – Data analysis environment

## Datasets

The project uses multiple COVID-19 datasets:

- `country_wise_latest.csv`
- `covid_19_clean_complete.csv`
- `day_wise.csv`
- `full_grouped.csv`
- `usa_country_wise.csv`
- `worldometer_data.csv`

## Key Analysis and Visualizations

1. Global COVID-19 statistics
2. Country-wise confirmed cases and deaths
3. Recovery and active case comparisons
4. Top 20 countries by confirmed cases
5. Population-to-testing ratio
6. Death-to-confirmed ratio
7. Death-to-recovered ratio
8. Time-series analysis of COVID-19 cases
9. Country-specific analysis using interactive charts

## How to Run the Project

1. Clone this repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

2. Install the required libraries:

```bash
pip install pandas numpy plotly jupyter
```

3. Open Jupyter Notebook:

```bash
jupyter notebook
```

4. Open the project notebook and run the cells sequentially.
